Before the check starts

Here is exactly what OpenCheck reads, and what it will never do.

What it reads

  • File and folder namesCompared to the cheat list. File contents are never opened.
  • Program historyWindows' records of which programs ran and when.
  • Deleted filesThe drive's change log and Recycle Bin, cheat names only.
  • Roblox settingsFastFlags from Roblox, bootstrappers and FastFlag files you downloaded.
  • System checksCleared logs, PC resets, lag-switch firewall rules, VMs, emulators and DMA hardware.

What it never does

  • Delete, move or change anything
  • Connect to the internet or send your report anywhere
  • Read passwords, browsing, Discord, photos or documents
  • Install itself or keep running after you close it

The report only lists matches. Your other files are never written down.

    How it works

    Windows keeps records of programs that ran and files that were deleted, even after the program itself is gone. OpenCheck reads those records and compares the names to a built-in list of Roblox cheats.

    A match is evidence, not proof. Files can be renamed, and an innocent file can share a name with a cheat. A moderator makes the final call.

    A fingerprint (SHA-256) is a unique ID worked out from a file's contents. The same file always gets the same fingerprint, and changing even one byte gives a completely different one.

    The report shows this app's own fingerprint, so moderators can compare it with the official download and know the app wasn't modified. Cheat files that match the list get a fingerprint too, so the exact version can be identified even if it was renamed.
