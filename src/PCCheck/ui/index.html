Before the check starts

This is exactly what OpenCheck reads, and what it will never do.

What it reads

  • File and folder namesCompared to the cheat list. Other files are never opened, except Roblox script files, which are checked for executor-only functions.
  • Program historyWindows' records of which programs ran and when, crash reports, and which files were deleted. PowerShell history is only checked for commands that wipe these records.
  • Roblox settings and game historyFastFlags, plus which games were open and when, from Roblox's own logs. Only game IDs and times are kept.
  • System, network and device checksCleared logs, PC resets, VMs, DMA hardware, VPNs, firewall history, internet drops, USB drives and sandbox tools. A PC ID made from hardware models is added to the report.

What it never does

  • Never deletes, moves or changes anything
  • Never connects to the internet or sends your report
  • Never reads passwords, browsing, Discord, photos or documents
  • Never installs itself or keeps running after you close it

The report only lists matches. Your other files are never written down.

      How OpenCheck works

      Windows keeps records of programs that ran and files that were deleted, even after the program itself is gone. OpenCheck reads those records and lines them up with what cheats are known to leave behind.

      A match is evidence, not proof. Files can be renamed, and an innocent file can share a name with a cheat. Staff make the final call.

      A fingerprint (SHA-256) is a unique ID worked out from a file's contents. The report shows this app's own fingerprint, so staff can compare it with the official download and know the app wasn't changed.

      For staff

      Run checks on a live screenshare, with OpenCheck downloaded fresh from the official site while you watch. On the report, compare the version, the fingerprint and the PC ID under "Verify this check" with what's on their screen. Evidence is ranked: Strong is a cheat match, Worth asking needs an answer from the player, and Context is background. Each item suggests what to ask.
